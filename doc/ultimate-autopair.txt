Advanced-pair-creation              *ultimate-autopair-advanced-pair-creation*

First, example of lua multiline string (e.g. `[=[`,`]=]`):
>lua
 {
  priority=10, --Set higher priority than `[]`
  {'[', --The key that triggers the pairing. If the pair is not dynamic (e.g.
        -- it is always the same) then it is recommended to set this to the
        -- true pair (for better auto prioritization).
   function (con,fns) --{con} is context, {fns} is table of helper functions
    local eq=fns.pair_match(con,'%[(=+)','%[')
    -- The reason why we need to separate the last char match is because when
    -- inserting start pair then the last char is not yet present
    if not eq then return end
    -- Returning nil means that the pair is not inserted
    return '['..eq..'[',']'..eq..']'
    -- Handling of things like that `[]` paired before is handled internally
    -- So you just need to return the whole pair
   end
  },
  {']',function (con,fns)
    local eq=fns.pair_match(con,'%](=+)%]')
    -- In this case you don't need to separate the last char match because
    -- such situation where this is needed will never occur
    if not eq then return end
    return '['..eq..'[',']'..eq..']'
  end}
 }
<
The function may also return a third value of a table, which contains the
following key-values:
- {[1]}: The true start pair, useful when you want to distinguish between
  the detection of open/close pairs and the inserted pair
- {[2]}: The true end pair, same as above
  (example: `return '[',']',{nil,'];'}` will match opennes using `]` but
   insert(/jump-over/delete/...) `];`)
